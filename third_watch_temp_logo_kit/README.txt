Third Watch Studios — Temporary Logo Kit

Source: cropped from the preferred brand-board logo image. These files are meant for short-term use while a designer redraws the logo as original vector artwork.

Recommended use:
- Use third-watch-logo-lockup-dark-bg-2048w.png for websites, pitch decks, and temporary brand presentations.
- Use third-watch-logo-lockup-transparent-glow-2048w.png only on dark navy/charcoal backgrounds.
- Use third-watch-emblem-transparent-glow-1536w.png for large icon/emblem use on dark backgrounds.
- Use favicon files for temporary favicon/app icon testing.
- Use brand-card files for temporary in-game splash/brand cards.

Important limitations:
- These are processed raster files, not final professional source artwork.
- The wordmark should eventually be rebuilt with a licensed font or custom vector type.
- The final logo should be professionally redrawn as clean vector art before public launch, printing at scale, trademark use, or merch.

Short-term best practice:
- Use dark-background PNGs for polished presentation.
- Use transparent PNGs on dark surfaces only.
- Use the emblem-only files for favicons/social icons.
- Avoid using the full text lockup at tiny sizes.
