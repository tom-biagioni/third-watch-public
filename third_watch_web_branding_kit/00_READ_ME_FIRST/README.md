# Third Watch Studios - Web Branding Kit

This kit is a short-term, website-ready branding package built from the current Third Watch Studios logo direction.
It is intended for a splash page, pitch materials, temporary web presence, social avatars, favicons, and game splash-card mockups.

## Start here

1. Open `04_web_splash_starter/index.html` in a browser.
2. Edit the contact link and copy in `index.html`.
3. Use `08_tokens/third-watch.tokens.css` for color variables in your website.
4. Use the PNG logo assets for short-term web use.
5. Replace these temporary raster/logo-trace assets with a designer-redrawn vector master when you are ready for production.

## Core identity

- Tower: vigilance, endurance, remote signal, not a literal lighthouse.
- Amber window: the human light inside vast darkness.
- Circular aura: watch cycle, midnight signal, time, quiet resilience.
- Wordmark: premium cinematic serif, wide tracking, restrained and literary.

## Palette

- Deep Sea Navy: #071419
- Charcoal: #111416
- Storm Gray: #4E585B
- Fog Stone: #B8B2A6
- Warm Amber Beacon: #D69B4B

## Practical usage

- Use dark backgrounds for the current logo assets.
- Use the no-tagline logo most often; the tagline is too small for many applications.
- Use the emblem for favicon, social avatar, Discord, and game UI stamps.
- Use the full lockup for splash screens, website hero sections, and pitch decks.
- Use amber sparingly as an accent, not as a full background color.

## Production caveat

The included SVG files are temporary vector approximations. They are useful for layout testing, but they are not a final professional vector identity. For launch, print, merchandise, and trademark use, commission a designer to redraw the tower, aura, and wordmark as original vector artwork.
