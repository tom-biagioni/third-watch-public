# Logo Usage Notes

## Recommended files

- Website hero: `02_logo_assets/png/third-watch-logo-lockup-transparent-glow-2048w.png`
- Website nav/footer: `02_logo_assets/png/third-watch-logo-lockup-transparent-flat-2048w.png`
- Social avatar: `05_social_and_open_graph/third-watch-social-avatar-1080.png`
- Favicon: `07_favicons/favicon.ico` or PNG sizes
- In-game splash: `06_game_splash_cards/third-watch-game-splash-1920x1080.png`
- Temporary SVG: `02_logo_assets/svg/third-watch-logo-lockup-temporary-vector.svg`

## Short-term limits

These assets are suitable for prototypes, splash pages, mockups, pitch decks, and initial web use.
They should not be treated as final print/trademark-ready masters.

## Before launch

Have a designer rebuild the mark and wordmark as original vector artwork, then regenerate all assets from the vector master.
